# Online4Tech Receiver Manager

مشروع مستقل لإدارة أجهزة Enigma2 من خلال واجهة ويب عربية، مع الحفاظ الكامل على مستودع وموقع Online4Tech الرئيسي دون تعديل.

## الحالة الحالية
- واجهة عربية RTL متجاوبة.
- جسر محلي يعمل على Windows عبر `127.0.0.1:8765`.
- فحص حالة الجسر عبر `/health`.
- اتصال SSH بالرسيفر وقراءة معلومات النظام عبر `/run`.
- فحص معلومات الجهاز ومساحة التخزين والخدمات.
- إنشاء نسخة من إعدادات Enigma2 وTuxbox عبر `/download-backup`.
- اكتشاف تلقائي للشركة والموديل وصورة النظام وإصدارها ومدة التشغيل من مخرجات Enigma2.
- كلمة مرور SSH لا تُحفظ في Local Storage ولا تُرفع إلى GitHub؛ تبقى في ذاكرة الصفحة أثناء الجلسة فقط.

## التوافق
الواجهة لا تفترض موديل Vu+ بعينه؛ بل تقرأ حقول تعريف الجهاز من مخرجات Enigma2، ولذلك يمكنها عرض موديلات Vu+ وDreambox وغيرها متى كانت صورة النظام تعرض حقول التعريف القياسية. يظل التوافق الفعلي مرتبطاً بدعم الجهاز لـ Enigma2 وSSH والأوامر المسموح بها في الجسر.

## النشر على GitHub Pages
1. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)`.
2. الرابط:
   `https://online4tech.github.io/Online4Tech-Manager/`

## ملاحظات الأمان
- GitHub Pages لا يستقبل بيانات دخول الرسيفر.
- الجسر المحلي يستمع على loopback فقط، ويقبل Origin الموقع المحدد.
- CORS ليس بديلاً عن المصادقة؛ يلزم إضافة اقتران محلي برمز قصير العمر وحماية من CSRF قبل توسيع العمليات.
- لا تفتح SSH أو منافذ الرسيفر على الإنترنت.
- لا تُنفذ أوامر Shell حرة من المتصفح؛ استخدم قائمة العمليات المحددة في الجسر.
- العمليات التي تغيّر إعدادات الجهاز تحتاج تأكيداً صريحاً ونسخة احتياطية قبل التنفيذ.

## خارطة التطوير
1. إكمال بطاقة تعريف الجهاز التلقائي والتحقق منها على أكثر من موديل.
2. تحسين عرض معلومات النظام والتخزين والخدمات.
3. إضافة إدارة آمنة لملفات القنوات والبلجنات والنسخ الاحتياطية.
4. إضافة عمليات صيانة اختيارية بعد وضع نظام تأكيد واسترجاع واضح.
5. تقوية الاقتران المحلي وحماية الجسر قبل دعم الاستخدام من أجهزة أخرى على الشبكة.

## البنية
واجهة GitHub Pages → الجسر المحلي على Windows → SSH داخل الشبكة المحلية → جهاز Enigma2.

ملفات الجسر المحلية لا تُرفع إلى هذا المستودع حالياً؛ يجب أن تظل إعدادات التشغيل وكلمات المرور محلية.
