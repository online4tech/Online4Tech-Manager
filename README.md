# Online4Tech Receiver Manager

مشروع مستقل لإدارة أجهزة Enigma2 من خلال واجهة ويب، مع الحفاظ الكامل على مستودع وموقع Online4Tech الرئيسي دون تعديل.

## الحالة الحالية
- واجهة عربية RTL متجاوبة كبداية للمشروع.
- روابط أولية لموقع Online4Tech ومستودعاته.
- إعداد عنوان Bridge محلياً داخل المتصفح.
- لا توجد أوامر رسيفر مفعّلة حتى الآن؛ يجب أولاً فحص كود Online4Tech Bridge الحالي وتوثيق API الفعلية وسياسة CORS والمصادقة.

## النشر على GitHub Pages
1. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)`.
2. بعد النشر سيكون الرابط المتوقع:
   `https://online4tech.github.io/Online4Tech-Manager/`

## الأمان قبل تفعيل التحكم
- لا تضع كلمات المرور أو مفاتيح SSH داخل ملفات الواجهة أو GitHub.
- يجب أن يتحقق Bridge من Origin المسموح به، وأن يستمع على loopback فقط.
- استخدم مصادقة محلية ورمز جلسة قصير العمر، مع منع الطلبات غير المصرح بها.
- لا تنفذ أوامر Shell حرة قادمة من المتصفح. استخدم قائمة عمليات مسموح بها ومتحققاً من مدخلاتها.
- العمليات المؤثرة تحتاج تأكيداً واضحاً وسجلاً محلياً.
- لا تفتح SSH أو منافذ الرسيفر على الإنترنت.

## الخطوة التالية
فحص نسخة Bridge الحالية على جهاز Windows (المتوقع أنها تعمل على `127.0.0.1:8765`) وتحديد مسارات API الحقيقية قبل ربط الأزرار.
